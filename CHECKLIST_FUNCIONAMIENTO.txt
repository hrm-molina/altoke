PARTE B — REGISTRO DE USUARIO (el rol que busca servicios)
================================================================================

B1. Abrir registro
[ ] Click "Regístrate gratis" en el hero → se abre el modal de registro
[ ] O click "Iniciar usuario" → "Regístrate acá" → abre el registro de usuario

B2. Paso 1 — Tipo de persona
[ ] Se puede elegir "Usuario" y "Prestador"
[ ] Elegir "Usuario" y avanzar

B3. Paso 2 — Email y contraseña
[ ] Poner un email inválido (ej: "abc") → aparece error, no avanza
[ ] Poner contraseña corta (ej: "123") → aparece error
[ ] Poner email válido + contraseña de 8+ caracteres → avanza

B4. Paso 3 — Datos personales
[ ] Campos: nombre, teléfono, fecha nacimiento, región, comuna, términos
[ ] Teléfono inválido (ej: "123") → error
[ ] Fecha de nacimiento de menor (hoy menos 10 años) → error o bloqueo
[ ] Elegir región → las comunas de esa región aparecen en el desplegable
[ ] Cambiar de región → las comunas cambian
[ ] Sin marcar "acepto términos" → error, no registra
[ ] Links de Términos/Privacidad en el checkbox abren en nueva pestaña

B5. Completar el registro
[ ] Registrar con email y contraseña que NO existan → éxito
[ ] Llega email de confirmación a la bandeja (revisar spam también)
[ ] Click en el link de confirmación → email queda confirmado
[ ] Verificar en Supabase (Auth → Users): el usuario aparece confirmado
[ ] Verificar en Supabase (tabla usuarios): aparece la fila con tipo='usuario'

PARTE C — LOGIN Y SESIÓN
================================================================================

C1. Login correcto
[ ] "Iniciar usuario" → email correcto + contraseña → entra a /explorar

C2. Login con errores (probar los 3)

[ ] Email inexistente → mismo mensaje (no revela si el email existe)
[ ] Email registrado pero SIN confirmar → mensaje pidiendo confirmar
      + botón para reenviar el email de confirmación

C3. Sesión
[ ] Recargar la página → la sesión se mantiene
[ ] Cerrar el navegador, abrir de nuevo → según diseño, se mantiene o pide login (anotar cuál)
[ ] Click en cerrar sesión (logout) → vuelve a la landing y ya no hay navbar de sesión
[ ] Con sesión cerrada, escribir directamente la dirección /explorar → NO entra (lo manda a login)

PARTE D — EXPLORAR SERVICIOS (función principal)
================================================================================

D1. Ver el catálogo
[ ] Entrar a /explorar como usuario → se ven servicios (o estado vacío si no hay datos)
[ ] Si no hay servicios registrados, se entiende el mensaje ("no hay servicios" o similar)

D2. Filtros
[ ] Escribir en el buscador → filtra por texto
[ ] Elegir región → solo quedan servicios de esa región
[ ] Elegir comuna (tras elegir región) → filtra
[ ] Poner precio mínimo/máximo → filtra
[ ] Botón de limpiar filtros → vuelve a la lista completa

D3. Abrir un servicio
[ ] Click en un servicio → se abre el detalle (modal o vista)
[ ] Se ve: título, categoría, descripción, valor, zona
[ ] Sección de teléfono oculta con mensaje "Haz clic para mostrar el teléfono"

D4. Ver teléfono (flujo clave)
[ ] Click en "ver teléfono" estando LOGUEADO → aparece el número real
[ ] Verificar en Supabase (tabla alertas): se creó una alerta pendiente para el usuario

D5. Calificar
[ ] En la alerta o en el flujo de "calificar" → se abre el formulario de reseña
[ ] Intentar enviar sin estrellas → bloqueado
[ ] Intentar enviar sin texto de reseña → bloqueado
[ ] Poner 3 estrellas + un texto → se envía correctamente
[ ] Verificar en Supabase (tabla calificaciones): aparece la reseña
[ ] Verificar que el rating del servicio se actualizó (aparece el promedio nuevo)

D6. Auto-calificación (trampa de seguridad)
[ ] Con la cuenta del PRESTADOR, intentar calificar su propio servicio → debe estar bloqueado

D7. Historial
[ ] Navbar → "Mi Historial" (o /explorar?tab=historial)
[ ] La reseña que hiciste aparece con estrellas, fecha y texto
[ ] Pestaña "Servicios" → vuelve al catálogo

D8. Alertas
[ ] Navbar → "Alertas" (o /explorar?tab=alertas)
[ ] Aparece la alerta pendiente del servicio que viste
[ ] Botón "Sí" (contraté) → la alerta avanza a la opción de calificar
[ ] Botón descartar/no → la alerta desaparece
